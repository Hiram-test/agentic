# 能力边界与验证声明

## 已通过自动化验证的能力

1. BSDL Core 与 Industrial Schema、稳定 ID、引用、拓扑和工业语义验证。
2. 梁、壳、实体、T3D2 预应力筋和混合显式 FE 模型到 CalculiX 关键字的确定性转换。
3. FE 集合/表面、材料/截面、边界、荷载、摩擦接触、四种预应力表示和施工阶段 deck 生成。
4. CalculiX deck 静态检查、受控外部进程、超时、线程、日志、错误识别、真实文件 SHA-256 和运行清单。
5. DAT 位移、反力、应力和应变回读，FRD/DAT/INP/LOG 等产物写入 BSDL ResultSet 修订。
6. 版本化规则包、安全表达式、逐条验算结果、计划状态、修订和审计链。
7. IFC 4.3 可选依赖检测、项目 MVD Profile、源身份映射和转换报告契约。
8. 响应式手机界面、Pointer Events 触控、PWA 清单、Service Worker 和安装入口。
9. Docker、Nginx、非特权用户、API 密钥、健康检查、持久化数据库/作业卷和环境路径配置。
10. 经验数据库原位迁移、修订差异提取、跨项目结构描述符、经验质量/状态、相似度门槛、读回预览、待审核策略补丁和人工经验审核。

## 当前环境没有完成的验证

1. 当前交付环境没有原生 `ccx`，未执行 CalculiX 2.23 数值求解和 FRD 场结果可视化认证。
2. 没有对某一实际桥梁完成设计级材料、接触、张拉、施工阶段、荷载组合和规范参数校核。
3. 没有 buildingSMART 官方 MVD 认证，也没有跨多款 IFC 软件的无损往返承诺。
4. 内置规则包不是正式桥梁规范，不包含受版权保护条文，不能自动签发设计符合性结论。
5. 当前部署为单节点 SQLite 基线，不等同于多租户、高可用、灾备和大规模集群平台。
6. 经验相似度属于确定性工程启发式，尚未用大规模独立桥梁数据校准为概率，也未证明对接触、强非线性、施工阶段和整体稳定等新物理机制可靠泛化。
7. 经验读回只生成 `needs_review` 补丁，不能替代后验误差估计、网格收敛、原生 CalculiX 验证和工程责任审批。

## 原生投产前必须补充的证据

- CalculiX 2.23 版本与构建选项记录、官方测试集和项目最小基准。
- 梁/壳/实体单元补丁测试、接触启闭、预应力解析解和施工阶段回归。
- 刚体模态、反力平衡、能量、收敛、网格独立性和结果符号/坐标检查。
- 实际 IFC 文件的项目 MVD、单位、坐标、GlobalId、几何和属性映射测试。
- 正式规则包的版权/许可、条文版本、参数来源、独立复核和责任人批准。
- 服务器访问控制、HTTPS、备份、磁盘配额、作业并发、监控和恢复演练。
- 跨专家、跨桥型和跨时间留出集上的经验读回校准、冲突消解、概念漂移与负面经验回归。

## 表述约束

“已实现”表示相应语言对象、确定性代码路径、接口、夹具和自动测试存在；“可运行”还要求部署环境提供真实依赖；“工程可用”需要通过项目级数值、互操作、规范和责任审查；“认证”只能由有权机构或经过授权的组织给出。本交付不把接口占位、静态 deck 或测试替身描述为已经完成的商业/原生求解器认证。
