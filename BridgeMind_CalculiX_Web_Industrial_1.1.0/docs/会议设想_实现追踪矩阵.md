# 会议设想—实现需求追踪矩阵

| 老师设想 | 本项目实现位置 | 状态 |
|---|---|---|
| 以 joint、link、origin 等基本概念描述桥梁 | BSDL 的 Node、Component、Connection、CoordinateSystem | 已实现 |
| 描述几何、材料、截面、约束和连接属性 | BSDL Schema、示例模型、语义验证器 | 已实现 |
| 三维模型分割后由统一语言整理 | 点云 Importer 与 BSDL 构件生成 | 已实现可运行路径 |
| 点击三维部件联动显示 JSON | Web 端 Canvas 选择与属性/JSON 面板 | 已实现 |
| 全局资源分配加局部多 expert AMR | cognition/expert 与 fusion 模块 | 已实现规则化原型 |
| 节点、突变区、连续平滑区分类 | SupportJoint、Discontinuity、Smooth expert | 已实现 |
| 人工新增、删除区域框和修改参数 | Web 区域编辑器与版本保存 | 已实现 |
| V1、V2、V3 全部进入数据库 | SQLite RevisionRepository | 已实现 |
| 人工经验与 FEA 计算双反馈 | Human feedback 与 builtin frame3d feedback | 已实现 |
| 快速试算任务与状态 | Run 数据表、API、Web 任务列表、时间与过程曲线 | 已实现 |
| 修改过程沉淀为 QA/经验 | Revision diff 与 ExperienceExtractor | 已实现 |
| 提示词/策略模板可版本化、设为默认 | Template 数据表、prompts 目录与 Web 模板管理器 | 已实现 |
| 形成局部有限元认知地图 | landmarks、decisionEdges、feature signatures | 已实现 |
| 点云/BIM 作为上游入口 | XYZ/CSV 点云完整路径；IFC 为可插拔 Adapter | 点云已实现，IFC 预留 |
| 连接 CalculiX 等计算包 | CalculiX B31 deck exporter 与可选执行器 | 导出已实现，外部二进制按环境执行 |
| 从简单三维案例走通最小闭环 | 双主梁桥、空间悬臂梁、预生成 V2/V3 产物与自动化工作流测试 | 已实现 |
| 后续扩展壳/实体、真实 AMR、多求解器 | Adapter 与 Expert Protocol、BFEA-CIR 映射边界 | 已预留 |

本版本刻意没有宣称完成工业级 IFC 几何内核、商业求解器全部功能或全寿命 11-agent 平台。会议要求的第一阶段可运行闭环已经落地，长期目标通过稳定接口继续扩展。
