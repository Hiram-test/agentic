# BridgeMind Studio 1.1.0 + BSDL Industrial 1.0 实现说明与使用手册

> 本文覆盖当前网站、CalculiX 工业扩展和 1.1.0 跨项目经验读回链。


## 1. 实现目标

BridgeMind Studio 以 BSDL 作为三维结构、有限元认知、网格策略、人工修改和计算反馈之间的公共语义层。系统首先把桥梁表达成稳定对象及关系，再让不同 expert 对局部结构提出区域级网格动作，由确定性网格器和求解器执行；人工修改与 FEA 反馈采用同一对象模型保存，因此每一次 V1、V2、V3 变化都可以比较、回读、归档并转化为经验。

## 2. BSDL 语言对象

BSDL 文档由以下对象族构成：

- `Project / Revision / Agent`：项目身份、不可变修订和责任主体。
- `CoordinateSystem / Node / Component / Connection`：三维结构、局部坐标和构件连接。
- `Material / Section / Constraint`：材料、截面和六自由度约束。
- `LoadCase / Load / AnalysisTask`：荷载工况、节点荷载、任务、精度和计算预算。
- `Region / MeshPolicy`：三维区域框、来源、语义类别、网格等级、目标尺寸和区域优先级。
- `CognitiveMap`：局部地标、结构特征、条件与下一步网格动作。
- `Feedback`：Agent 建议、人工修改和 FEA 结果反馈。
- `Artifact`：点云、网格、求解器输入、日志和结果文件引用。

物理结构对象和策略对象具有稳定 ID，区域通过 `targetRefs` 指向节点、构件或连接，网格策略通过 `regionRules` 指向区域，认知地图再把局部特征与动作关联起来。

## 3. 语言验证

`bridge_mind/validator.py` 依次检查：

1. JSON Schema 结构、类型、枚举和必填字段。
2. 全局 ID 唯一性和跨对象引用存在性。
3. 坐标系正交性、节点位置和线构件端点。
4. 活跃空间梁的材料、截面和非零长度。
5. 荷载工况、目标节点、区域目标和网格规则。
6. 求解前至少存在约束和非零荷载。

验证问题采用稳定 `ruleId`、严重度、对象路径、目标 ID、期望值和实际值，便于 Web、Agent 或测试程序进行局部修复。

## 4. 多 expert 认知策略

认知模块先从 BSDL 提取节点度数、支承、构件长度、相邻夹角、材料/截面变化、结构包围盒和可选 FEA 响应，再由以下 experts 生成三维区域提案：

- `SupportJointExpert`：识别约束节点和支承邻域。
- `JointExpert`：识别连接构件较多或方向突变的节点。
- `DiscontinuityExpert`：识别截面、材料和几何特征变化。
- `SmoothExpert`：识别可采用较粗网格的连续平滑构件。
- `FEAHotspotExpert`：根据端力、位移或响应分位数生成热点区。
- `HumanOverrideExpert`：保持人工确认、修改或驳回意见的最高优先级。

Fusion 模块按空间重合、目标对象和语义类型融合提案，保留来源、置信度和理由；GlobalAllocator 根据结构尺度、任务精度和元素预算确定基准尺寸。最终每个活跃区域转换为 `MeshPolicy.regionRules`，同时形成 `CognitiveMap.landmarks` 和 `decisionEdges`。

## 5. 内置快速 FEA

内置求解器用于形成快速、确定性计算反馈，支持：

- 3D Euler–Bernoulli 梁单元，每个节点 6 个自由度。
- 轴向、扭转和两个弯曲方向的 12×12 局部刚度矩阵。
- 任意空间方向局部坐标和全局坐标变换。
- 根据 `MeshPolicy.baseSize` 与区域规则自动分段。
- 节点力、节点矩、六自由度约束和边界消元。
- 位移、反力、单元端力、最大轴力/剪力/弯矩与反力平衡。

该求解器用于 Demo、回归测试和快速策略反馈。工程设计应通过受控 Adapter 输出到经验证的商业或开源求解器，并保存转换报告和原生输入。

## 6. 三维 Web 工作流

启动后，按以下流程操作：

1. 在顶部选择项目；中央画布支持旋转、缩放、单击选择和双击聚焦。
2. 点击“验证”，检查当前浏览器内尚未保存的完整 BSDL 文档。
3. 点击“Agent 策略”，生成区域、认知地图和网格策略并保存新修订。
4. 在“有限元认知地图”中点击地标，定位对应区域或结构对象。
5. 点击“快速试算”，生成网格、数值结果、过程指标和 FEA 热点反馈。
6. 选择区域后，在右侧修改语义类型、来源、状态、网格等级、目标尺寸、中心和尺寸。
7. 使用“新增人工框”或“删除/驳回框”，形成带 before/after 的人工反馈。
8. 点击“保存 V+”形成工作修订，点击“归档 V+”封存人工确认快照。
9. 选择两个相邻修订并点击“提取经验”，把差异和最近运行指标写入经验库。
10. 在模板区编辑结构问卷、网格策略或经验摘要，保存新版本并可设为同类默认。
11. 使用 BSDL、Gmsh 或 CalculiX Adapter 导出外部文件。

## 7. 数据库与版本

SQLite 包含五张主表：

- `projects`：项目索引和当前修订。
- `revisions`：完整 BSDL 不可变快照、父修订、作者、来源、状态和内容哈希。
- `runs`：求解输入、状态、结果、错误和时间。
- `experiences`：跨项目描述符、相对策略动作、适用范围、修改前后、证据、质量、状态和审核记录。
- `templates`：模板稳定 ID、版本、类别、正文和默认状态。

Web 编辑只改变当前会话对象，点击保存后才写入新修订；历史对象不会被原地覆盖。区域删除采用 `rejected + active=false`，因此其历史和人工判断仍可审计。

## 8. 点云入口

点云 Importer 支持 XYZ、空格分隔文本和 CSV：

1. 读取三维点并过滤非法行。
2. 采用体素质心进行确定性降采样。
3. 使用 DBSCAN 识别空间点簇。
4. 对每个点簇执行 PCA，得到中心、主方向、尺度和细长度。
5. 生成线、盒或点代理构件以及导入区域。
6. 输出合法 BSDL 初始项目，等待人工或模型补充材料、截面、连接和分析属性。

## 9. API

关键 API 包括：

- `POST /api/validate`：验证当前会话 BSDL 文档。
- `GET/POST /api/projects`：读取或创建项目。
- `GET/POST /api/projects/{id}/revisions`：读取和保存修订。
- `POST /api/projects/{id}/strategy`：生成多 expert 策略并可读取历史经验。
- `POST /api/projects/{id}/memory/preview`：无副作用预览经验匹配和拟议补丁。
- `POST /api/projects/{id}/solve`：执行快速 FEA 并可写回反馈修订。
- `GET /api/projects/{id}/runs`：读取试算任务。
- `POST /api/projects/{id}/experiences/extract`：从两个修订提取经验。
- `GET /api/experiences`：按项目、关键词和状态检索经验。
- `POST /api/experiences/{id}/review`：接受、拒绝或归档经验。
- `GET/POST /api/templates`：读取或保存模板版本。
- `POST /api/import/point-cloud`：上传点云并创建项目。
- `POST /api/projects/{id}/export`：导出 BSDL、Gmsh 或 CalculiX。

完整 OpenAPI 描述见 `docs/openapi.json`。

## 10. 经验读回链

`bridge_mind/memory.py` 把当前 Region 转换为与项目 ID 和绝对坐标解耦的结构—任务描述符，再对历史 Experience 执行语义类型、单元族和分析类型硬门槛，以及支承、节点度数、约束、构件类别、截面突变和尺度等软相似度评分。多个合格经验按相似度与质量分聚合为相对网格动作，读回后的区域统一进入 `needs_review`，并保存经验 ID、匹配分数、质量分、策略版本和应用字段。

经验读回默认只修改 Agent 来源的区域，不能自动修改材料、荷载、边界或拓扑。浏览器的“读回预览”不会保存修订；“使用经验”开关控制 Strategy 和快速 FEA 反馈阶段是否把历史经验放入计算路径。经验审核状态会即时决定其是否可供未来策略使用。

## 11. 研究实验

建议以双主梁桥和空间悬臂梁完成第一轮实验，评价：结构识别覆盖率、区域定位精度、人工修改次数、网格规模、位移/内力 QoI、平衡残差、版本可重放率和经验复用收益。后续可把规则 expert 分别替换为检索、大模型、PSO、强化学习或图模型，并保持同一 BSDL 输入输出接口进行消融比较。

## 12. 扩展边界

BSDL 保留面、实体、接触、阶段、结果 artifact 和外部求解器扩展位置，但 0.1.0 的确定性求解核心只覆盖线弹性空间梁。IFC Adapter 要求绑定 IFC 4.3 版本、MVD、IfcOpenShell 几何设置和 conformance fixtures 后实施；在这些条件未满足前，系统会明确报告能力不可用或映射尚未实现，不进行静默转换。
