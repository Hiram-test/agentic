# 会议设想与工业实现追踪矩阵

| 老师设想 | 当前实现 | 主要文件 | 验证方式 |
|---|---|---|---|
| 类 URDF 的统一结构语言 | 节点、构件、面、实体、连接、坐标、材料、截面和约束 | `schema/bsdl-industrial.schema.json` | Schema 与引用测试 |
| 点云/BIM 到标准问卷 | XYZ/CSV 分割、IFC 4.3 可选导入、结构问卷模板 | `importers/point_cloud.py`、`importers/ifc.py` | 导入测试与 ConversionReport |
| 三维结构“炸开”和部件联动 | 三维画布、选择、属性/JSON 联动 | `web/app.js` | 浏览器与静态接口测试 |
| 有限元认知地图 | landmark、decision edge、region 和 feature signature | `cognition/` | 多专家策略测试 |
| 全局资源分配 + 局部 expert | 全局预算、支承/突变/平滑/热点/人工 expert | `cognition/orchestrator.py` | 策略输出与 L4 验证 |
| 手机像画图板一样交互 | 单指、双指、长按、抽屉、底部快捷栏 | `web/` | PWA/触控契约测试 |
| 区域级 0/1 与参数修改 | region 状态、网格等级、目标尺寸和人工覆盖 | BSDL `regions`、`meshPolicies` | 修订与并发测试 |
| 快速试算反馈 | 内置梁系预览 + CalculiX 工业链 | `fea/frame3d.py`、`adapters/calculix.py` | 求解器替身与结果回写测试 |
| 壳和实体单元 | S3/S4/S4R 与 C3D 系列显式 FE | `finiteElementModels` | 工业示例和 deck lint |
| 非线性接触 | 主从表面、摩擦、阶段启闭 | `contacts` | 接触关键字与引用测试 |
| 预应力 | 等效荷载、筋单元、初始应力、原生预紧 | `prestressingSystems` | 两个专用 deck 夹具 |
| 施工阶段 | 多阶段激活/移除、荷载和预应力状态 | `constructionStages` | 五 STEP 工业 deck |
| 规范验算 | 版本化规则包和逐条利用率/证据 | `code_checks/`、`rules/code_checks/` | API 与写回测试 |
| V1/V2/V3 全量保留 | SQLite 不可变修订、baseRevision 冲突保护 | `repository.py` | 修订测试 |
| 人工经验 + FEA 双反馈 | feedback、resultSets、experience 提取 | `experience.py` | 经验与运行测试 |
| Prompt/skill 版本沉淀 | 模板版本、默认模板、审计 | `templates` 表、`prompts/`、`skills/` | API 测试 |
| 网站和产品化 | FastAPI、PWA、Docker、Nginx、健康检查 | `api.py`、`web/`、部署文件 | 部署契约测试 |
| 工业 IFC 4.3/MVD | IfcOpenShell Adapter、项目 Profile、源 ID 和损失 | `mvd/`、`importers/ifc.py` | MVD 测试 |
| 不重复造轮子 | IFC/IfcOpenShell、CalculiX、Gmsh、JSON Schema | Adapter 分层 | 能力矩阵和边界声明 |

当前完成的是单节点可部署的工业研究闭环。面向正式生产还需在目标服务器执行原生 CalculiX 基准、配置正式规范规则包、使用实际桥梁 IFC 完成项目 MVD conformance，并根据并发量把 SQLite/本地作业执行迁移为 PostgreSQL、独立队列和对象存储。
