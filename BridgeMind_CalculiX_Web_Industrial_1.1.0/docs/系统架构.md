# BridgeMind Studio 系统架构

## 1. 分层

系统分为感知输入层、BSDL 语义层、认知与策略层、确定性计算层、交互与版本层、经验复用层。点云或 BIM 只负责提供几何与初始对象；BSDL 是所有后续模块的公共结构表示；多 expert 只生成区域和参数建议；网格与求解由确定性工具完成；人工修改和计算反馈都进入同一修订链；经验抽取器把修订差异转成局部模式。

## 2. 数据流

`XYZ/CSV/BSDL/IFC → Importer → BSDL Model → Validator → Feature Extractor → Rule Experts → Fusion → Memory Descriptor → Experience Retrieval/Scoring → Proposed Region/MeshPolicy Patch → Human/FEA Review → Revision Store → Experience Store → Policy Pack`

## 3. 关键模块

- `validator.py`：Schema、引用、拓扑、力学和求解前检查。
- `features.py`：节点度数、支承、角度、属性突变、构件长度和包围盒特征。
- `experts.py`：全局分配、节点支承、突变、平滑、FEA 热点与人工覆盖。
- `fusion.py`：三维包围盒重合判定、提案合并、优先级和预算归一化。
- `frame3d.py`：12×12 空间梁单元、刚度组装、边界消元、反力与端力回算。
- `repository.py`：SQLite 项目、修订、运行、结构化经验、审核状态和模板持久化。
- `experience.py`：把修订差异编译为描述符、相对动作、适用范围、证据和质量。
- `memory.py`：跨项目检索、硬兼容门槛、加权相似度、动作聚合和待审核 BSDL 补丁。
- `api.py`：项目、验证、策略、求解、修订、经验、点云导入和 Adapter API。
- `web/`：自包含三维画布、区域编辑、JSON 联动、结果和修订视图。

## 4. 研究可替换点

每个 expert 实现统一接口，可以替换为规则、检索、强化学习、PSO、图网络或大模型。FusionEngine 不依赖具体 expert。内置 frame3d 可以替换为 CalculiX、OpenSees、Abaqus、Ansys 或自研求解器。经验摘要器可以替换为外部 LLM，但必须输出结构化经验对象并保留来源。


## 5. 经验读回的状态边界

基础模型、规则 expert 和求解器可以保持不变，系统行为由 `Experience Store + memory_policy + current BSDL state` 共同条件化。经验只有重新进入 Strategy 路径才构成读回；仅保存日志不会改变未来策略。所有读回补丁必须可追溯、可拒绝、可回滚，并在 FEA 或人工批准前保持 `needs_review`。
