# 最小实验与论文评估设计

## 实验 A：结构语言与三维联动

使用双主梁桥 BSDL 示例，验证对象覆盖、引用完整率、三维选择与 JSON 联动正确率。对节点、构件、连接、支承、荷载和区域分别执行新增、修改和删除操作，检查修订可重放性。

## 实验 B：多 expert 区域识别

构造支承节点、横梁交汇、截面突变、长平滑梁段和人为热点五类区域，分别统计 expert 的召回率、重复提案数、融合后区域数、人工接受率和参数修改量。

## 实验 C：人工—FEA 双反馈

对 V1 全局均匀策略、V2 Agent 策略、V3 人工修订策略和 V4 FEA 反馈策略进行比较，记录最大位移、关键单元端弯矩、区域数量、估算单元数、人工操作次数和运行时间。

## 实验 D：跨项目经验读回

由专家 A 在 8—12 个训练项目中形成 support、joint、discontinuity 和 hotspot 的人工/FEA 修订，提取并审核为 accepted 经验；随后冻结代码、基础模型、规则和经验库，让未参与训练的新用户 B 处理严格留出的测试项目。控制组设置 `useMemory=false`，实验组设置 `useMemory=true`，其余输入完全一致。

测试项目分为三层：同类结构插值、已知局部模式的新组合、未见物理机制。第一层检验固化，第二层检验组合泛化，第三层检验拒绝与 FEA 纠错能力。被历史经验改变的区域必须保持 `needs_review`，错误迁移同样纳入指标。

## 推荐指标

结构表达覆盖率、Schema 有效率、引用完整率、专家提案准确率、区域 IoU、人工增删次数、参数修改幅度、FEA 成功率、刚体模态错误率、最大位移差、关键内力差、版本重放率、经验检索命中率、经验应用率、首次建议接受率、错误迁移率、新用户人工修改次数、闭环迭代次数和 wall-clock。
