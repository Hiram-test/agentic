# 移动端触控与公网部署

## 1. 响应式界面

桌面端采用三维主视图、结构/属性面板、任务与版本面板；手机端自动切换为全屏三维画布、左右抽屉和底部快捷栏。触控事件统一使用 Pointer Events：单指拖动旋转，双指距离变化缩放，双指中心移动平移，点击选择构件或区域，长按选中局部区域并打开编辑入口。画布设置 `touch-action: none`，防止浏览器滚动手势与三维操作冲突。

## 2. PWA

`manifest.webmanifest` 定义应用名称、图标、启动页和独立显示模式；Service Worker 缓存应用壳和核心静态资源，离线时仍可打开界面和浏览已缓存页面。涉及项目、求解和最新修订的数据仍以服务器为准，离线壳不伪造在线计算结果。公网安装 PWA 需要 HTTPS；localhost 可在开发环境使用安全上下文例外。

## 3. 本地与局域网

`python scripts/run_lan.py` 绑定 `0.0.0.0` 并打印本机与局域网地址。手机必须与电脑处于同一可互访网络；企业或校园 Wi-Fi 可能启用客户端隔离，此时需要使用实验室路由器、服务器公网域名或 VPN。不要把未设置访问控制的开发服务直接暴露到互联网。

## 4. 容器部署

`Dockerfile` 使用非特权用户、单 Uvicorn worker、健康检查和独立持久化路径；`docker-compose.yml` 编排应用、Nginx、SQLite 卷、作业卷和只读 `solver` 目录；Nginx 设置 512 MB 上传上限和 24 小时长作业代理超时。单 worker 是当前 SQLite 一致性边界，如需横向扩展，应把数据库迁移到 PostgreSQL、把作业队列迁移到独立 Worker，并使用对象存储保存大结果文件。

## 5. CalculiX 挂载

交付包不捆绑平台特定二进制。管理员把经过许可和项目验证的 CalculiX 2.23 `ccx` 放到 `solver/ccx`，Linux 赋予执行权限；Compose 以只读方式挂到 `/opt/calculix/ccx`。若文件缺失，容器仍健康运行，但 `/api/calculix/status` 显示不可用，工业运行请求返回明确状态。

## 6. 安全

设置 `BRIDGEMIND_API_KEYS` 后，除健康、能力和求解器状态外的 `/api/` 请求都要求 `X-API-Key`。电脑和手机网页在“服务器访问”区域接收密钥，只写入当前标签会话的 `sessionStorage`，请求封装自动添加 `X-API-Key`，界面和日志不会回显密钥；401 响应会清除无效会话凭据。应用同时启用 MIME 嗅探防护、同源 Frame、Referrer 和设备权限策略；产物下载限制在 `runs` 根目录，上传文件使用随机名称，修订提交采用乐观并发。API 密钥是单节点研究部署基线，公网多用户系统还应配置 HTTPS、WAF/速率限制、备份、日志保留、磁盘配额、病毒扫描、正式身份提供方与细粒度项目授权。

## 7. 运维检查

- `/api/health`：应用、版本和项目数量。
- `/api/capabilities`：语言、触控、IFC、CalculiX、部署和限制矩阵。
- `/api/calculix/status`：真实 `ccx` 路径和可用状态。
- `/api/projects/{id}/runs`：任务状态、完成时间、网格统计和错误。
- `/api/audit`：导入、导出、求解、验算、修订和模板事件。

数据库和 `runs` 卷必须纳入备份；任何清理策略都应先确保修订引用的 artifact 已迁移或显式失效，不能直接删除仍被工程结论引用的文件。
