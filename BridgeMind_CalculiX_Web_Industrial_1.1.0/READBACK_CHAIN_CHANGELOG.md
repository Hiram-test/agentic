# BSDL Experience Readback Chain 1.1.0

本版本把原有日志、修订、经验和模板能力接入未来策略生成路径。专家修改不再只留在历史数据库中，而会被编译为带结构描述符、相对动作、适用范围、证据、质量和审核状态的 Experience；新项目运行 Rule Experts 后，Memory Compiler 检索兼容经验并生成 `needs_review` BSDL Patch。

关键安全约束：经验不会直接批准工程结果；分析类型、区域语义和单元族不兼容时硬拒绝；默认仅跨项目读取；单次动作有尺寸和等级变化上限；被拒绝或归档经验不再进入未来策略；所有应用均保留经验 ID、分数、策略版本和差异。

验证结果：30 项自动化测试全部通过；独立自检中，一个训练项目的已批准支座经验在项目 ID 和绝对坐标均变化的新项目中匹配并应用到 4 个支座区域，使目标尺寸由 0.5625 改为 0.28125、网格等级由 5 改为 7，同时保持人工审核状态。
