# Changelog

## 1.1.0 — 2026-08-14

- 接通 BSDL 经验写入—检索—筛选—读回—审核完整链路，不更新基础模型权重。
- 增加跨项目 Region 描述符，移除项目本地 ID 和绝对坐标对相似度核心的依赖。
- 增加经验 `descriptor`、`action`、`applicability`、`evidence`、`qualityScore`、`status` 和 `review` 数据。
- 增加旧版 SQLite 经验表原位迁移、幂等保存、按状态查询和人工接受/拒绝/归档。
- 增加版本化 `memory_policy` 模板、硬兼容门槛、加权相似度、质量加权动作聚合和安全裁剪。
- 经验读回只修改白名单策略字段，所有应用区域统一进入 `needs_review` 并保留来源证据。
- 增加 `/memory/preview` 和 `/experiences/{id}/review` API，以及网页读回预览、启用开关和经验审核按钮。
- 增加跨项目新用户继承、分析类型拒绝、旧数据库迁移和 API 审核四类自动化测试。
- 自检新增跨项目经验读回链，确认控制组与读回组产生可测量策略差异。

## 1.0.0 — 2026-08-13

- 将本地 BSDL 研究 Demo 升级为响应式手机触控 PWA 和可部署网站。
- 增加 BSDL Industrial 1.0 Schema、迁移、工业验证和能力矩阵。
- 增加 CalculiX 2.23 混合梁/壳/实体/T3D2 导出、静态检查、运行、DAT 回读和结果写回。
- 增加摩擦接触、四种预应力表示和施工阶段编译。
- 增加 IFC 4.3 可选导入、项目 MVD Profile、源身份与转换损失报告。
- 增加版本化规则包、规范验算结果和审计修订。
- 增加 API 密钥、生产路径、Docker、Compose、Nginx、健康检查和持久化卷。
- 增加工业示例、预应力夹具和工业/API/PWA/部署自动测试。
- 增加手机与桌面网页的浏览器会话密钥输入，自动附加 `X-API-Key` 并清除无效凭据。
