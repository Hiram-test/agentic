# CCX 六工况几何非线性计算（2026-10-14）

本目录归档 CalculiX 六工况几何非线性计算的实际输入和求解输出。六个工况均使用 `*STEP, NLGEOM`：C01 恒载、C02 恒载加施工荷载、C03 C02 加降温 15 ℃、C04 恒载加施工荷载和施工风、C05 恒载加最大阵风、C06 C02 加降温 34 ℃。

每个工况目录包含实际 `*.inp` 输入；存在的 `*.frd`、`*.sta` 和 `*.dat` 是对应求解输出。输入来自 BridgeMind CalculiX base 运行目录，保留原始字节内容。

运行示例：`ccx -i catwalk_base_C01`

该归档用于当前猫道模型的静力复核，结果不替代完整三维模型、整体稳定或单根索验算。
